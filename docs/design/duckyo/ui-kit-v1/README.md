## 图标

13款SVG，24×24画布、1.8px圆润线条，文字标签保留。图标随文字色显示，无独立PNG色彩版本。

| 范围 | 图标与含义 |
| --- | --- |
| 底部导航 | 打卡：便签勾选；激励：礼物袋；统计：柱形/趋势；我的：圆形头像与柔和肩线 |
| 打卡图案 | 嫩芽、打开的手账、水杯、笔直小路、圆靶、太阳 |
| 我的空间 | 来信、归档抽屉、打开的物品盒 |

SVG是新设计的功能符号；贴纸是现有原图像素裁切，两者分别记录。返回、添加、关闭等共同操作按钮不在本轮重做。图标ID候选与现有业务语义一致，确认后接入时不得修改既有打卡ID/记录或默认、露米图标映射。

## 贴纸

透明底256×256 PNG，建议显示64px；原图缩小，保留人物、表情、笔触、颜色及既有道具，不使用AI重绘、补画或新增装饰。不复用用户已删除的开心吃饭素材。

| 用途候选 | 原图 | 文件 |
| --- | --- | --- |
| 暂无打卡 | 专注写字 | stickers/first-step.png |
| 空收件箱 | 手机时光 | stickers/waiting-message.png |
| 暂无归档 | 打工小鸭（已去吊灯版本） | stickers/archive.png |
| 暂无物品 | 零食片刻 | stickers/inventory.png |

角色和原插画归Duckyo / 小刘鸭；原出处及既有素材记录见[项目素材来源](../../../../web/themes/duckyo/SOURCES.json)。各贴纸裁切坐标、桌面线条透明处理范围见[裁切记录](./sticker-sources.json)。抠图仅处理透明通道，保留源RGB，最后按比例缩小；打工素材使用项目既有去吊灯母版。

暂无物品贴纸仅展示未来空状态方向，不能把当前“库存尚未接通”伪装成真实空库存。全部完成、等待连接、失败、离线等状态需保持各自含义，不能一律套用“暂无打卡”贴纸和文案。
